# SMC Panic Decoder

Расшифровка кода из строки `S.sensor array` в SMC panic-логах iPhone
(`SMC PANIC - ASSERT ... SMC BSC failure`): какая деталь не отвечает контроллеру.

Открой `index.html` в браузере. Можно вписать код (десятичный или hex)
или вставить panic-лог целиком: модель и код определятся сами. Всё работает
локально, лог никуда не отправляется.

Таблица кодов взята из вики сообщества iFixit, Apple её не публикует:
https://www.ifixit.com/Wiki/iPhone_SMC_Panic_Assertion_Failed

Код указывает, где искать неисправность, но это не готовый диагноз: часто
виноват шлейф или разъём рядом с деталью.
